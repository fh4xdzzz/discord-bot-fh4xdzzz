# Política de Privacidad - FH4XDZzz Bot

## 1. Información General
El Bot FH4XDZzz ("el Bot") recopila y procesa ciertos datos para proporcionar sus servicios. Esta Política de Privacidad explica qué datos recopilamos, cómo los usamos y cómo protegemos tu información.

## 2. Datos que Recopilamos

### 2.1 Datos de Usuario de Discord
- ID de usuario de Discord
- Nombre de usuario y nombre para mostrar
- Avatar de usuario
- Servidores donde el Bot está activo
- Roles asignados en servidores

### 2.2 Datos de Actividad
- Mensajes enviados en canales donde el Bot está activo
- Tiempo en canales de voz (si está activado el tracking)
- Participación en sorteos y eventos
- Interacciones con comandos del Bot

### 2.3 Datos de Configuración
- Preferencias del usuario (suscripciones a notificaciones)
- Datos de niveles y experiencia (XP)
- Historial de moderación (advertencias, kicks, bans)

## 3. Uso de los Datos

### 3.1 Funciones del Bot
- **Sistema de niveles:** Recopilamos XP y niveles para el sistema de recompensas
- **Sorteos:** Recopilamos participantes y ganadores de sorteos
- **Moderación:** Recopilamos registros de acciones de moderación
- **Notificaciones:** Recopilamos suscripciones para enviar notificaciones relevantes
- **Logs:** Recopilamos información de actividad para el sistema de logs

### 3.2 Mejora del Servicio
- Analizamos patrones de uso para mejorar las funciones del Bot
- Utilizamos datos anónimos para corregir errores y mejorar rendimiento
- Recopilamos feedback de usuarios para mejorar funcionalidades

## 4. Almacenamiento de Datos

### 4.1 Ubicación
- Los datos se almacenan localmente en el servidor donde se ejecuta el Bot
- No utilizamos servicios de almacenamiento en la nube para datos de usuarios
- Los datos no se transfieren a terceros sin consentimiento explícito

### 4.2 Retención de Datos
- Los datos se retienen mientras el Bot esté activo en el servidor
- Los usuarios pueden solicitar la eliminación de sus datos contactando al desarrollador
- Los datos se eliminan automáticamente cuando el Bot se elimina de un servidor

## 5. Compartición de Datos

### 5.1 No Compartimos Datos con Terceros
- No vendemos, alquilamos ni compartimos datos de usuarios con terceros
- No utilizamos datos para publicidad o marketing
- No compartimos datos con otras aplicaciones o servicios

### 5.2 Excepciones
- Podemos compartir datos si es requerido por ley
- Podemos compartir datos para proteger nuestros derechos o propiedad
- Podemos compartir datos con desarrolladores del Bot para mantenimiento

## 6. Seguridad de Datos

### 6.1 Medidas de Seguridad
- Implementamos medidas de seguridad para proteger datos de usuarios
- Los datos se almacenan en formato JSON en el servidor del Bot
- No almacenamos información sensible como contraseñas o tokens

### 6.2 Acceso a Datos
- Solo el desarrollador del Bot tiene acceso a los datos almacenados
- Los datos no son accesibles públicamente a través de Internet
- Los administradores de servidores pueden ver sus propios datos a través de comandos del Bot

## 7. Derechos del Usuario

### 7.1 Acceso a Datos
- Los usuarios pueden solicitar acceso a sus datos personales
- Los usuarios pueden solicitar corrección de datos inexactos
- Los usuarios pueden solicitar eliminación de sus datos

### 7.2 Cómo Solicitar Acceso a Datos
- Contacta al desarrollador a través de Discord: FH4XDZzz
- Proporciona tu ID de usuario de Discord
- Especifica qué datos deseas acceder, corregir o eliminar

## 8. Cookies y Tecnologías Similares
- El Bot no utiliza cookies ni tecnologías de seguimiento web
- Discord puede utilizar cookies en su plataforma
- Consulta la Política de Privacidad de Discord para más información

## 9. Cambios a esta Política
Nos reservamos el derecho de modificar esta Política de Privacidad en cualquier momento
- Las modificaciones se publicarán en este documento
- El uso continuo del Bot después de modificaciones constituye aceptación de la nueva Política
